# Week 5 Assignment – Apache Spark Fundamentals using PySpark

## Data Engineering Internship – Celebal Technologies

### Objective

The objective of this assignment is to understand the fundamentals of Apache Spark and perform data cleaning, transformation, filtering, aggregation, and analysis using PySpark DataFrames. The assignment also demonstrates how Spark can efficiently process large datasets compared to traditional MapReduce.

---

## Technologies Used

- Python
- Apache Spark
- PySpark
- Jupyter Notebook
- CSV Dataset

---

## Dataset

**Dataset:** Superstore (Modified)

The dataset contains sales transactions along with customer, product, category, region, and store information. It has been used to demonstrate various Spark DataFrame operations such as data cleaning, filtering, aggregation, schema transformation, and data processing.

---

## Assignment Tasks

This assignment covers the following concepts:

- Apache Spark Fundamentals
- MapReduce vs Apache Spark
- Spark DataFrames
- Data Cleaning
- Removing Duplicate Records
- Handling Missing Values
- Filtering Records
- Data Transformation
- Aggregation Functions
- GroupBy Operations
- Schema Modification
- Shuffle and Wide Transformations
- Complete Data Processing Pipeline
