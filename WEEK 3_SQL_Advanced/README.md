---

## Assignment Details

- **Topic:** SQL Analysis using Subqueries, CTEs, and Window Functions
- **Dataset:** Superstore (Kaggle)
- **Tool:** SQL Server Management Studio (SSMS)

---

## Objective

The objective of this assignment is to analyze sales data using SQL by applying concepts such as:

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Business Analysis Queries

The assignment also focuses on database normalization and generating meaningful business insights from the Superstore dataset.

## How to Run

1. Open SQL Server Management Studio (SSMS).
2. Create the database by running the SQL script.
3. Import **Superstore.csv** into the **superstore_raw** table using the Import Flat File Wizard.
4. Execute the remaining SQL script in sequence.
5. Verify the query outputs and compare them with the screenshots provided in the report.
