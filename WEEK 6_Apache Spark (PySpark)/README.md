# Week 6 - Apache Spark (PySpark)

## Overview

This repository contains my Week 6 assignment completed as part of the Celebal Technologies Data Engineering Internship.

The objective of this assignment was to understand Apache Spark architecture and perform data processing using PySpark. The assignment covers reading datasets, applying transformations, filtering data, handling schemas, working with CSV and Parquet files, and understanding Spark performance concepts.

---

## Assignment Objectives

- Understand Apache Spark Architecture
- Learn Driver, Cluster Manager and Executors
- Understand Lazy Evaluation and DAG (Lineage Graph)
- Read CSV and Parquet files
- Perform DataFrame transformations
- Filter records using different conditions
- Rename and cast columns
- Create new calculated columns
- Handle null values
- Compare CSV and Parquet file formats
- Learn Predicate Pushdown
- Build a simple Spark data pipeline
- Save processed data into CSV format
- Follow Spark best practices

---

- Apache Spark
